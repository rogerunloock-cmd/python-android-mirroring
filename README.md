# Espelhamento Android com Python

Aplicação gráfica desenvolvida em Python para controlar o espelhamento de dispositivos Android no Windows utilizando o scrcpy e o ADB.

## Funcionalidades

- Verificar se um dispositivo Android está conectado
- Iniciar o espelhamento da tela
- Espelhar mantendo a tela física do celular desligada
- Exibir mensagens de erro e status
- Interface gráfica simples com Tkinter

## Tecnologias utilizadas

- Python
- Tkinter
- scrcpy
- Android Debug Bridge — ADB

## Requisitos

- Windows 10 ou superior
- Python 3.10 ou superior
- Celular Android com Depuração USB ativada
- scrcpy para Windows
